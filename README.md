# Student Management System

A beginner-friendly Java project to manage student records.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Exit the application

## Student Details

The system stores:

- Student ID
- Name
- Age
- Course
- Marks

## Technologies Used

- Java
- ArrayList
- Scanner
- OOP Concepts

## How to Run

1. Download or clone this repository.
2. Open `StudentManagementSystem.java`.
3. Compile the program:
   `javac StudentManagementSystem.java`
4. Run the program:
   `java StudentManagementSystem`

## Project Purpose

This project was created to practice Java basics such as classes, objects, methods, ArrayList, loops, conditional statements, and switch-case.
